# Braspress Tracking Sheets

Integração entre a API de rastreamento da Braspress e Google Sheets,
desenvolvida em Google Apps Script.

O projeto automatiza a consulta do status de notas fiscais e atualiza
as informações de rastreamento diretamente na planilha.


## Tecnologias

- Google Apps Script
- Google Sheets
- Braspress Tracking API
- REST API
- Basic Authentication
- PropertiesService
